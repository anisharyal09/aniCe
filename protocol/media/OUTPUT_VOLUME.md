# Mac output volume extension v1

[CDDL](output-volume.cddl) defines `["aniCe output volume", 1, kind, fields]` in existing authenticated DATA, at most 4,000 bytes. Deterministic CBOR and validation rules match the separately named [player-volume extension](PLAYER_VOLUME.md). Media v1 and player-volume v1 bytes remain unchanged. Each peer advertises this extension independently; older peers remain connected without output controls.

| Kind | Fields |
| --- | --- |
| 1 | `[1]` capability |
| 2 | `[subscription, output, revision, supported, level]` sample |
| 3 | `[subscription, commandID, output, revision, level]` command |
| 4 | `[subscription, commandID, result]` result |

Subscription/output/revision are 36-byte UUID strings. Supported samples require nonempty output/revision and integer level 0–100. Unsupported samples use level −1; output/revision are both empty or both valid. Commands require integer ID 1–2^32−1, nonempty output/revision and level 0–100. Results use the media typed codes: applied 0, stale 1, unsupported 2, permission-needed 3, denied 4, unavailable 5, busy 6, failed 7. Wrong versions, lengths, types, bounds, noncanonical encodings and oversized records are discarded.

The Mac binds an opaque output identity to the native default-output device ID, UID and chosen settable scalar property. Device replacement, support loss or observation stop retires that identity; level-only samples preserve revision. Reads/writes revalidate the native destination, never retarget a command to a different output, and never use scripting, simulated keyboard events or an audio mixer. The native virtual-main property preserves device channel balance; the main scalar property is the alternative. Fixed-volume outputs advertise no support. Native default-device/volume notifications provide output-only samples without polling or resending playback metadata. Explicit refresh rechecks current support.

The existing single secured media subscription owns routing, lifecycle, queue preflight and capacity. Command IDs and bounded deduplication are shared with media and player volume; reuse across kinds returns stale rather than executing another action. Retirement cancels unsent requests and previews; reconnect never replays a write. An uncertain outcome is not retried.

Android's foreground volume buttons and native MediaSession remote [VolumeProvider](https://developer.android.com/reference/android/media/VolumeProvider) control this output while genuine compact playback is active. Relative adjustments are five percentage points. The absolute Android provider advertises 20 steps, mapping each native step to five points; authoritative current level is rounded to the nearest native step. Foreground key callbacks retain the actual percentage base. One executing request and one latest unsent intent bound repeated presses; only an applied result may submit the retained intent. A matching authoritative level confirms preview; failure, device replacement, disconnect or a fixed six-second deadline clears it with feedback. The output target includes subscription identity, preventing callbacks from retired providers from executing in a replacement session. When unavailable, foreground keys retain normal Android routing; no background media service, audio focus or LAN activation is added. Background system controls retain existing companion-owned secured BLE requirements and the 90-second presentation grace.
