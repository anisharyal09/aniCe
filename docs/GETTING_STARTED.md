# Connect your Mac and Android phone

1. On the Mac, open aniCe, choose **Add device**, then choose **Show QR code** or **Show six-digit code**.
2. On Android, open aniCe and choose **Add device**. Scan the Mac's QR code or select **Six-digit code** and enter the displayed code.
3. Check the device name and approve pairing on both screens.

After approval, the devices appear in Home and Devices. If an invitation expires or pairing is declined, start a new invitation from the Mac.

Pairing uses the existing Bluetooth setup flow. aniCe asks for required Android permissions when you start the action that needs them. See the [pairing contract](../protocol/pairing/README.md) for the protocol details.
