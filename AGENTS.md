# Working in aniCe

Before making changes:

1. Read `.agents/CONTEXT.md`.
2. Read `.agents/RULES.md` and `.agents/RULES2.md`*.
3. Read `.agents/STATE.md`.
4. Read `.agents/NOTES.md` where relevant.
5. Inspect applicable human documentation, protocol definitions, and existing code before introducing changes.

For any UI or frontend task, you must read [docs/design/DESIGN.md](docs/design/DESIGN.md) before writing code.

Human documentation records product and architecture intent. `protocol/` owns communication contracts. `.agents/` provides operational coding context.
